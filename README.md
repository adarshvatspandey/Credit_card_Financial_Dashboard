# 💳 Credit Card Financial Dashboard

## 📊 Project Overview

The **Credit Card Financial Dashboard** is an interactive **Power BI Business Intelligence solution** designed to analyze credit card transactions, customer behavior, revenue performance, and financial metrics. The dashboard provides actionable insights that help businesses monitor key performance indicators (KPIs), identify high-value customer segments, track spending patterns, and make data-driven decisions.

This project consists of **two interactive dashboards**:

### 📌 Credit Card Customer Report

# 📈 Dashboard KPIs

| KPI                      | Description                                         |
| ------------------------ | --------------------------------------------------- |
| Revenue                  | Total revenue generated from credit card operations |
| Interest Earned          | Total interest earned from customers                |
| Total Transaction Amount | Overall transaction volume                          |
| Transaction Count        | Total number of transactions                        |
| Income                   | Total customer income                               |
| CSS                      | Customer Satisfaction Score                         |
