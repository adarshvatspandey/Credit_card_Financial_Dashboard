Credit Card Financial Dashboard
📊 Project Overview

The Credit Card Financial Dashboard is an interactive Power BI analytics solution designed to provide comprehensive insights into credit card transactions, customer behavior, revenue performance, and financial metrics. This project consists of two dashboards:

Credit Card Transaction Report – Focused on transaction analysis, revenue generation, card performance, and expenditure patterns.
Credit Card Customer Report – Focused on customer demographics, income groups, customer satisfaction, and behavioral insights.

The dashboards enable stakeholders to monitor KPIs, identify high-value customer segments, analyze spending trends, and support data-driven decision-making.
